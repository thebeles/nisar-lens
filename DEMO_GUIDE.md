# Как проверить NISAR Lens

За 5–7 минут вы откроете один радарный снимок, сравните два прохода спутника, посмотрите пример анализа воды и откроете данные о влажности почвы. Инструкция рассчитана на первый запуск и использует подписи кнопок из режима **EN**.

## 1. Запустить проект

В терминале откройте папку с `package.json`. Если зависимости ещё не установлены, выполните первую команду. Затем запустите сервер.

```bash
npm install
npm run dev
```

Откройте адрес, напечатанный в терминале, обычно [http://localhost:5173/](http://localhost:5173/). Оставьте сервер запущенным. Для основного сценария в проекте уже есть каталог, два обзорных изображения GCOV, пример анализа воды и данные Шпицбергена. Вводить токен для этих шагов не требуется.

**Ожидаемый результат.** На странице видны карточки регионов, фильтры, глобус и список наблюдений. Если включён русский интерфейс, переключите **EN** в правом верхнем углу или ориентируйтесь на русские названия в скобках ниже.

## 2. Открыть один снимок

1. В разделе **Where should we look?** нажмите **Meghna Baseline**. Это встроенный каталог наблюдений.
2. В **Product** выберите **GCOV**. Фильтр оставит записи этого типа. На чистом встроенном каталоге ожидается **17 из 154**. В общие 154 входят 153 записи архива и отдельный пример влажности почвы.
3. Над глобусом нажмите **Open selected image** («Открыть выбранный снимок»). Под названием кнопки указаны тип и дата. Для этого сценария выберите **GCOV · 2026-10-04**. Если выделена другая запись, нажмите строку с нужной датой в списке справа, затем откройте **SAR Browse** в карточке.

**Ожидаемый результат.** В карточке **SAR Browse** виден цветной радарный PNG и подпись **NASA EARTHDATA**. Для встроенного снимка также есть отметка **COPY INCLUDED WITH THE APP**.

GCOV — тип научного продукта NISAR с данными об отражённом радарном сигнале. В карточке показана его обзорная картинка. Условные цвета помогают различать детали радарного сигнала. Цветной контур на глобусе показывает, какую территорию покрывает наблюдение.

## 3. Сравнить две даты

1. Вернитесь к кнопкам над глобусом и нажмите **Compare two NISAR images** («Сравнить два снимка NISAR»).
2. Убедитесь, что **Date A** — **22 сентября 2026**, **Date B** — **4 октября 2026**, а рядом указаны **GCOV**, **12 Days**, **Trk 69 / Frm 15**.
3. В режиме **Split Curtain (A ◄► B)** перетащите вертикальный разделитель влево и вправо. Проведите им через тёмное русло, чтобы посмотреть один и тот же участок на обеих датах. Разделитель также можно выделить клавишей Tab и двигать стрелками.
4. Нажмите **Swap A/B**. Проверьте, что даты поменялись местами. Нажмите ещё раз, чтобы вернуть исходный порядок.

**Ожидаемый результат.** Камера приближает область съёмки, оба изображения видны на глобусе, а граница между ними движется вместе с разделителем. Это два реальных наблюдения. Для быстрой загрузки используются уменьшенные копии PNG NASA Earthdata из проекта. Снимок B — тот же, который вы открывали отдельно.

Сильного изменения местности может быть не видно. Цель этого шага — убедиться, что интерфейс позволяет сравнить один участок на двух датах. Разница в цвете сама по себе не подтверждает затопление.

## 4. Посмотреть результаты и их ограничения

1. Нажмите **Brightness difference** («Разница яркости»). Легенда показывает, где обзорное изображение B темнее или светлее A.
2. Нажмите **Brightness threshold** («Порог яркости»). Легенда показывает пиксели ниже порога на обеих датах или только на одной. Если доступен **Opacity**, сдвиньте его, чтобы изменить прозрачность слоя.
3. Нажмите **View estimates and export** («Открыть оценки и экспорт»). Сдвиньте **Relative brightness threshold** и посмотрите, как меняются доли пикселей. При желании скачайте **Export Report JSON** и **Download mask PNG**. В JSON указаны ID двух снимков, источники, метод и количество пикселей по классам.
4. Там же раскройте **Water analysis example from GCOV science data** («Пример анализа воды по научным данным GCOV»). Откроется готовая карта для отдельной области и пары **27 июня → 9 июля 2026**. Красный на этой карте означает, что алгоритм отнёс участок к воде только во вторую дату, жёлтый — только в первую.

**Ожидаемый результат.** Режимы меняют слой и легенду, а в деталях видна сводка и загружается отдельная карта. Веб-оценка использует яркость обзорных PNG. Отдельная карта рассчитана по радарному каналу HH продукта GCOV на общей сетке. При показе жюри называйте оба результата оценками по выбранному методу.

## 5. Открыть данные влажности почвы

1. Нажмите **Exit Compare** над картой.
2. В верхнем ряду карточек выберите **L3 Soil Moisture**. Это отдельный встроенный пример. Карточка **Svalbard Arctic** запускает поиск в каталоге по координатам.
3. Посмотрите, куда перелетела камера, и прокрутите до карточки **SAR Browse**, чтобы увидеть сводку по сетке.

**Ожидаемый результат.** Глобус приближает Шпицберген. В карточке видны **561 ячейка**, шаг сетки **200 м** и статистика объёмной влажности. **SME2** — тип продукта NISAR с оценками влажности почвы.

## 6. Дополнительные проверки

| Что проверить | Куда нажать | Что должно произойти |
| --- | --- | --- |
| Фильтры | **Meghna Baseline → Product → GCOV**, затем в **From** укажите **2026-10-01** | Остаются два GCOV-наблюдения. **Reset** возвращает полный список. |
| Автоподбор пары | Выберите **GCOV · 2026-10-04** и нажмите **Compare** у строки или **Compare Repeat-Pass Pair** над списком | Подбирается GCOV за 22 сентября с теми же параметрами прохода. |
| Ручной выбор пары | На полном архиве нажмите **Choose two dates manually**, затем **A** у GCOV за 22 сентября. Попробуйте **B** у RSLC за 4 октября, потом **B** у GCOV за 4 октября | Сначала появится объяснение, почему продукты несовместимы. После выбора второго GCOV откроется сравнение. |
| Живой поиск | Укажите широту **23.81** и долготу **90.41** и нажмите **Search NASA ASF**. Карточки регионов запускают такой же поиск по готовым координатам | Появится сообщение с числом найденных записей, а список обновится. Поиск зависит от доступности ASF. **Meghna Baseline** возвращает встроенный архив и сбрасывает фильтры. |
| Сохранение | В карточке откройте **Metadata → Pin Watchpoint**, затем **QA & Saved Items** | Запись появится в закладках этого браузера. В сравнении **Save comparison** сохраняет обе даты. |

### Остальные элементы

- **From / To** ограничивают даты съёмки. **Matching Passes** показывает число записей после фильтрации, **Coverage** — диапазон дат всего загруженного каталога.
- **More map views** («Ещё виды карты») раскрывает управление камерой. **3D Peaks** переносит к Гималаям, **Svalbard L3** — к сетке Шпицбергена, **Target** — к району Мегхны и Брахмапутры, **Globe** — к общему виду Земли. **L0B Strips** показывает или скрывает длинные полосы исходных проходов.
- **Metadata** показывает параметры записи и ссылки. **SAR Browse** показывает обзорный снимок и доступные варианты изображения. **QA & Saved Items** показывает проверки качества и закладки. **Overview** собирает эти блоки вместе.
- **Open Full PNG** открывает полноразмерный обзорный PNG. **Download HDF5** открывает научный файл, который может весить несколько гигабайт. Для защищённых файлов нужен серверный `EARTHDATA_TOKEN`. Для живых запросов при локальной проверке используйте `npm run dev`.

## Если что-то не открылось

- **Страница недоступна.** Проверьте, что `npm run dev` ещё запущен, и откройте адрес из терминала.
- **Каталог открыт, глобус пуст.** Проверьте, что браузер поддерживает WebGL и включено аппаратное ускорение. Детальная подложка карты может зависеть от внешних сервисов.
- **Не загрузилась онлайн-пара.** Посмотрите сообщение над картой и нажмите **Retry** («Повторить»). Для проверки интерфейса воспользуйтесь встроенной парой через **Compare two NISAR images**.

## Что сказать жюри

> NISAR Lens помогает найти радарные наблюдения NASA–ISRO и сравнить их на карте. Сначала я открою один снимок, затем покажу два прохода над той же территорией с разницей в 12 дней. Разделитель позволяет посмотреть один участок на обеих датах. Отдельно в приложении есть пример анализа водной поверхности по данным GCOV и пример влажности почвы на Шпицбергене.
